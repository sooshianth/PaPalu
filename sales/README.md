# مستندات ماژول فروش (Sales)

## ایجاد مشتری

### رابط کاربری:
تمام صفحات فروش از قالب پایه `base.html` استفاده می‌کنند و دارای:
- منوی سایدبار و ناوبری یکسان
- طراحی سبز و ساده مطابق با طراحی کلی سیستم
- Responsive برای موبایل و تبلت
- استایل یکپارچه در تمام بخش‌ها

### ویژگی‌های سیستم ایجاد مشتری:

#### 1. کنترل دسترسی با TaskPermission
- برای دسترسی به ویو ایجاد مشتری، کاربر باید دارای تسک `sales.create_customer` باشد
- این دسترسی از طریق نقش‌ها (Roles) یا دسترسی‌های خاص کاربر (UserTaskPermission) تعریف می‌شود

#### 2. کنترل دسترسی فیلدها با FieldAccessRule
- فیلدهایی که کاربر به آنها دسترسی ندارد، در فرم نمایش داده نمی‌شوند
- برای تعریف محدودیت‌های دسترسی فیلد، از مدل `FieldAccessRule` استفاده می‌شود

#### 3. فیلدهای اجباری:
- **کد ملی (national_id)**: باید 10 رقم و یکتا باشد
- **نام شخص (name)**: نام کامل شخص یا شرکت
- **نوع (nature)**: حقوقی یا حقیقی
- **شماره همراه**: باید با 09 شروع شود و 11 رقم باشد

#### 4. فیلدهای اختیاری:
##### اطلاعات پایه:
- شماره ثبت شرکت (برای اشخاص حقوقی الزامی است)
- شماره ثابت
- تاریخ تولد
- معرف
- نوع کاربری
- توضیحات

##### اطلاعات مالیاتی:
- کد اقتصادی
- کد پستی مالیاتی
- استان مالیاتی
- شهر مالیاتی
- آدرس مالیاتی

##### آدرس تحویل:
- کد پستی تحویل
- نام تحویل گیرنده
- کد ملی تحویل گیرنده
- شناسه یکتا تحویل
- استان و شهر تحویل
- آدرس تحویل
- شماره‌های تماس هماهنگی تحویل
- محدودیت تحویل
- نوع تحویل گیرنده

##### اطلاعات نماینده:
- نام نماینده
- سمت نماینده
- شماره موبایل نماینده
- شماره ثابت نماینده
- نامه تایید نماینده

#### 5. قوانین خاص:
- **قانون حقوقی/حقیقی**: برای اشخاص حقوقی، شماره ثبت شرکت الزامی است
- **قانون شماره همراه**: باید با الگوی 09xxxxxxxxx مطابقت داشته باشد
- **قانون دسترسی کارشناس فروش**: هر مشتری فقط توسط کارشناس فروش خودش قابل مشاهده است (به جز superuser)

### استفاده از API:

#### URL ها:
```python
# ایجاد مشتری جدید
/sales/customer/create/

# لیست مشتریان
/sales/customer/list/
```

#### مثال استفاده در کد:
```python
from core.RBACModel import user_has_task, TaskChoices

# بررسی دسترسی کاربر
if user_has_task(request.user, TaskChoices.SALES_CREATE_CUSTOMER.value):
    # کاربر دسترسی دارد
    pass
```

### تنظیمات دسترسی:

#### 1. تعریف TaskPermission:
در پنل مدیریت Django، یک TaskPermission با تسک `sales.create_customer` ایجاد کنید.

#### 2. تخصیص دسترسی به کاربر:
دو روش وجود دارد:
- **از طریق نقش (Role)**: نقش را به کاربر اختصاص دهید
- **مستقیم**: از طریق UserTaskPermission دسترسی مستقیم به کاربر بدهید

#### 3. تعریف محدودیت فیلد (اختیاری):
برای محدود کردن دسترسی به فیلدهای خاص:
```python
from access.models.FieldAccessUserModel import FieldAccessRule
from django.contrib.contenttypes.models import ContentType
from core.PersonFolder import Person

# محدود کردن دسترسی ویرایش فیلد economic_code
content_type = ContentType.objects.get_for_model(FinancialBanking)
FieldAccessRule.objects.create(
    user=user,
    content_type=content_type,
    field_name='economic_code',
    access_type='edit',
    allowed=False
)
```

### نکات مهم:
1. هر مشتری به طور خودکار به کارشناس فروش فعلی (کاربر لاگین شده) اختصاص داده می‌شود
2. در لیست مشتریان، هر کاربر فقط مشتریان خود را می‌بیند (به جز superuser)
3. فیلدهایی که دسترسی به آنها وجود ندارد، در فرم نمایش داده نمی‌شوند
4. اطلاعات مالیاتی برای صدور پیش‌فاکتور ضروری است

### مدل‌های مرتبط:
- `Person`: اطلاعات اصلی شخص
- `PhoneNumber`: شماره‌های تماس (با GenericForeignKey)
- `FinancialBanking`: اطلاعات مالیاتی و بانکی
- `DeliveryAddress`: آدرس‌های تحویل
- `Representative`: نمایندگان شخص
- `PurchasePreference`: ترجیحات خرید
- `PaymentPreference`: ترجیحات پرداخت
- `SocialNetwork`: شبکه‌های اجتماعی
- `Attachment`: پیوست‌ها (مثل کارت ملی، روزنامه رسمی)
