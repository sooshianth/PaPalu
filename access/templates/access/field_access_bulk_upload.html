راهنمای ساخت فایل اکسل

ستون‌های موردنیاز (ردیف اول باید عنوان ستون‌ها باشد):

    {% for key, desc in excel_columns %}
  • {{ key }}: {{ desc }}
    • {% endfor %}

- اگر allowed خالی باشد، به صورت پیش‌فرض True در نظر گرفته می‌شود.
- برای model نام کلاس مدل را بنویسید (مثال: PersonModel). اگر ContentType با پسوند Model یافت نشد، تلاش می‌شود بدون پسوند هم بررسی شود (مثال: person).
- برای access_type تنها یکی از مقادیر view، edit یا delete مجاز است.

مثال‌ها را در فایل نمونه دانلودی مشاهده کنید.
